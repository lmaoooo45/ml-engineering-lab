# Краткие технические задания

## 1. Тональность русских отзывов

Нужно определить, положительный, отрицательный или нейтральный отзыв написал пользователь. Вход: непустая строка до 4000 символов. Выход: исходный текст, метка, уверенность, название модели в JSON. Длинный по числу токенов текст обрезается до ограничения токенизатора: заключительная часть отзыва может не попасть в модель.

Модель: cointegrated/rubert-tiny-sentiment-balanced. Запуск через Transformers на CPU. Отдельная функция анализа должна позволять добавить API позднее. Проверка: вручную размеченные отзывы, accuracy, macro-F1 и матрица ошибок. Ошибочные входы должны отклоняться до загрузки модели.

## 2. Распознавание русской речи

Нужно получить текст короткой записи. Вход: WAV, FLAC или OGG, поддерживаемый libsndfile, до 30 секунд. Выход: распознанная строка, длительность и название модели. Модель: openai/whisper-tiny. Стерео переводится в моно, частота дискретизации - в 16 кГц. Язык явно задан: русский, задача: транскрипция. MP3 и произвольные видеофайлы этим интерфейсом не поддерживаются.

Проверка: несколько записей с вручную записанными эталонными текстами, WER и время обработки. Отдельно проверяются разные частоты дискретизации и превышение длительности. Whisper может выдавать текст даже на тишине; это ограничение модели, а не доказательство наличия речи.

## 3. Классификация изображений

Нужно определить вероятное содержимое фотографии в пределах классов ImageNet. Вход: файл изображения, читаемый Pillow. Выход: от 1 до 1000 классов с вероятностями, по умолчанию top-5. Модель: MobileNetV2 с весами ImageNet, Keras Applications. Изображение приводится к RGB, исправляется ориентация EXIF, размер меняется на 224 × 224, применяется стандартный preprocess_input.

Проверка: фотографии с классами из ImageNet, top-1/top-5 accuracy и время обработки. Модель классифицирует изображение целиком и не выдаёт рамки. Растяжение до квадратного размера может искажать предметы.

## 4. Обнаружение объектов на видео

Нужно получить рамки объектов на выбранных кадрах короткого видео. Вход: видео, декодируемое OpenCV; интервал обработки и порог уверенности. Выход: MP4 без звука и JSON с номером кадра, временем, ID класса COCO, уверенностью и нормированными рамками. Модель: tensorflow/ssd_mobilenet_v2/fpnlite_320x320/1 из TensorFlow Hub.

Проверка: видео с известными объектами, просмотр рамок, precision/recall при IoU не меньше 0.5 на вручную размеченных обработанных кадрах и время обработки. Рамки не переносятся на пропущенные кадры. Код должен освобождать файлы при ошибке; вход нельзя перезаписать выходным видео. Для длительных записей следует изменить накопление JSON в памяти; текущий вариант рассчитан на короткие учебные примеры.
