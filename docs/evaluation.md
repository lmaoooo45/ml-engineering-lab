# План проверки качества

Это план эксперимента, а не выполненные результаты.

| Задача | Проверочные данные | Эталон | Что измерить |
|---|---|---|---|
| Текст | 12 примеров из CSV, затем реальные отзывы | negative/neutral/positive | accuracy, macro-F1, матрица ошибок |
| Аудио | минимум 5 коротких записей, включая шумную | дословная ручная транскрипция | WER, длительность, время распознавания |
| Изображения | минимум 10 фотографий из классов ImageNet | ID класса ImageNet | top-1/top-5 accuracy, время |
| Видео | минимум 20 вручную размеченных кадров | class_id, bbox | precision/recall при IoU не меньше 0.5, время |

Для текста: `python -m ml_lab.evaluate_text examples/reviews.csv --output outputs/text_metrics.json`.
Для остальных задач сохраните вывод приложений и сопоставьте с ручной разметкой. При сопоставлении рамок каждый эталонный объект может соответствовать только одной предсказанной рамке того же класса. Несопоставленные предсказания - FP, пропущенные эталонные объекты - FN.

Не выбирайте примеры только после того, как увидели успешные ответы модели. Сначала зафиксируйте набор и разметку, затем выполняйте запуск. Укажите происхождение материалов и размер выборки. Несколько личных примеров дают иллюстрацию работы, а не оценку качества на всех возможных данных.

Для WER заранее задайте нормализацию: регистр, пунктуацию и правило записи чисел. Пустой эталон нужно оценивать отдельно: делить на ноль нельзя. Плохие ответы и нераспознанные объекты следует сохранить вместе с успешными.

Время первого запуска включает загрузку и чтение весов. Его запишите отдельно от повторной обработки. Указывайте CPU, версии библиотек и параметры (`every`, `threshold`, размер изображения).
