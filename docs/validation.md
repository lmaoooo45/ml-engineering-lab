# Проверка работы

Дата проверки: 10 октября 2026 года.

Среда: Linux x86_64, Python 3.12.14, CPU. Версии библиотек: PyTorch 2.7.1+cpu, TensorFlow 2.20.0, Transformers 4.51.3, TensorFlow Hub 0.16.1. Остальные версии записаны в requirements-lock.txt.

## Установка и тесты

Установка зависимостей и повторный запуск `scripts/install.sh` завершились без ошибок. `uv pip check` не нашёл конфликтов версий. PyTorch и TensorFlow импортируются и выполняют вычисления с тензорами. Справка всех четырёх команд открывается.

Результат `python -m pytest -q`: **9 passed**. Тесты проверяют перевод стерео в моно, изменение частоты дискретизации, ограничение длины аудио, неправильные тексты, фильтрацию рамок, расчёт метрик и запись JSON. Эти тесты не оценивают качество готовых моделей.

TensorFlow Hub использует pkg_resources, поэтому закреплён setuptools 80.9.0. Предупреждение об отсутствии CUDA не мешает работе на CPU.

## Изображения

MobileNetV2 обработала фотографию собаки из примера PyTorch Hub:
https://raw.githubusercontent.com/pytorch/hub/master/images/dog.jpg

Первый ответ: Samoyed (`n02111889`), score около 0.6408. Полный ответ находится в [image-example.json](image-example.json). Один пример не позволяет вычислить точность модели на датасете.

Также проверено однотонное изображение. Модель выдала классы даже для него, поэтому первый ответ не всегда означает, что предмет действительно есть на фото.

## Видео

SSD MobileNetV2 FPNLite обработала пять однотонных кадров. При пороге 0.5 объектов не найдено. Выходной MP4 прочитан повторно, в нём пять кадров.

Второй ролик состоял из трёх повторов фотографии собаки. Детектор на всех кадрах ошибочно выдал COCO 17, кошку, с оценками от 0.606 до 0.655. Ответ сохранён в [video-example.json](video-example.json). В выходном MP4 три кадра.

Эти проверки подтверждают чтение видео, запуск модели и запись результата. Качество на реальном видео с движением пока не измерено.

## Текст и аудио

Страницы и настройки моделей Hugging Face доступны, но загрузка весов через `us.aws.cdn.hf.co` возвращает HTTP 403. Загрузка также проверена стандартным клиентом Xet. Веса RuBERT и Whisper не получены, распознавание не выполнено. Accuracy, macro-F1 и WER не измерены.

Для продолжения нужно разрешить этот домен в сетевых настройках и повторить команды из README. Ключ доступа для выбранных публичных моделей не нужен.
